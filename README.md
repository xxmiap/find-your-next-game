# Find Your Next Game

Working prototype for CS-GY 6313 Information Visualization. Explore Steam games by shared tags, review evidence, and price in U.S. dollars.

## Run the prototype

1. From this repository, select **Code → Download ZIP**, then extract the ZIP.
2. Open `dist/index.html` in a browser. The catalog and dependencies are bundled in the HTML, so it opens offline without installation.

## Try the demo

Select **Reset**, then click **Make Platformer optional** to expand the default Risk of Rain search from 57 to 581 candidates. Click the **Rogue-like + Indie** row in **Shared tags** to see its 524 games highlighted in the linked reviews and price views.

See [README.txt](README.txt) for the data sources, visual encodings, and optional rebuild instructions.
